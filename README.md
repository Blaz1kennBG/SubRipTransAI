# AI-MovieSubtitor

## An app for translating subtitles ENG > BG
If you do not have "input" and "output" folders, create them in the root dir of the app.
App works by feeding the folder "input" with video files which contains subtitles channels, takes the first and translates it to Bulgarian.
Output files are the extracted .srt from the channels **and** the translated .srt named as the video file's name for convenience.
Each file also has a .txt file, with information how much each block of that given .srt file took to translate.
